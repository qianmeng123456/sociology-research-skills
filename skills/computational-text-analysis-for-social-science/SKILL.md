# 计算社会科学文本分析

先建立构念与证据链，再选择 NLP 技术。模型输出是测量候选；词频、主题、嵌入距离和大模型标签本身不证明社会现象存在或变化。

1. 定义构念、分析单位、目标总体、时间与机制。区分测量文本表达、作者特征、组织行为或总体态度；后者不能由文本样本直接推定。
2. 记录平台、接口/采集方法、过滤与缺失、删除和幸存偏差、机器人及重复。按合法且获准的数据范围工作，不默认将受限语料发送到外部模型。
3. 建立理论定义—可观察文本特征—标签规范—测量模型—验证证据链。包括纳入/排除和歧义例，区分真假表达、转述、讽刺、引用与否定。
4. 按作者、来源、时间等实际泄漏机制分割训练、开发和留出验证集；抽取有代表性的人工验证样本并保留分层设计及权重。预处理和调参不得用测试集标签。
5. 从可解释基线比较候选模型，核对中文分词、口语、方言、表情、词义漂移；不能照搬删除否定词或数字的英文清洗。
6. 报告类别分布、适用的 precision/recall/F1、混淆、校准与群体/时期误差；不只报告 accuracy。检验构念与外部指标的关系以及反例，但避免以同一代理指标循环验证。
7. 若使用大模型标注，保存模型版本、提示、设置、运行日期、抽样人工复核和不确定项；提示稳定不等于测量稳定。更换模型或跨时间比较需验证可比性。
8. 将分类误差及抽样设计纳入下游推断，说明误差传播方式和敏感性；关联分析与因果解释分开。平台文本不能无条件代表总体民意。

交付语料卡、构念/标注说明、切分与模型版本、实际验证结果、错误例及带限制的社会学解释。无语料或标签时只交付方案，不制造准确率。

原始方法入口：[Grimmer 与 Stewart，Text as Data](https://www.cambridge.org/core/journals/political-analysis/article/text-as-data-the-promise-and-pitfalls-of-automatic-content-analysis-methods-for-political-texts/F7AAC8B2909441603FEB25C156448F20)。软件 API 需按执行时官方文档核对。
