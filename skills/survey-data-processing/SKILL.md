# 调查数据处理

将平台导出转为可追溯的分析数据，保持原始值、合法跳题和研究性缺失的区别。

## 工作方式

1. 读取问卷版本和代码本，检查响应 ID、平台额外表头、编码、重复记录及合并键。
2. 逐题计算应答资格；缺失率分母使用实际应答人群。区分拒答、不知道、系统漏答和结构性跳题。
3. 先生成时长、直线作答、矛盾、重复和注意力检查标记，结合预测试和题目难度解释，预设排除规则并记录逐人理由。
4. 在合法有效取值上反向计分；按量表手册或明确的自编规则要求最少有效题数。全缺失的和分不能成为零。
5. 保留分层、PSU 和权重字段，导出变量标签、值标签及缺失码对照；运行从 raw 到 clean 的脚本并检查行数和范围。

## 交付

分析数据、代码本、清洗脚本、样本流转计数和质量标记说明。

## 方法修订与适用边界

不把 60 秒、90% 直线作答或一次注意力题失败作为通用删除门槛。上游均值/和分代码没有充分限制有效题数，不能原样使用。上游所谓 pyreadstat 写出 .rds 不适用；R 可用 saveRDS，跨软件可用 CSV 加代码本。

保留原始数据和处理记录；缺少数据时交付设计或代码草稿，不能填写虚构的样本量、系数、引文或已经完成的检验。代码执行前核对用户文件、软件版本与官方接口，只报告实际运行结果。
