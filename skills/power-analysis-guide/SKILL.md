# 功效与样本量

先区分精度规划和假设检验功效规划，给出有依据的范围。

## 工作方式

1. 确定主要结局、估计量、分析模型、单侧或双侧、显著性水平、目标功效和实际有意义的最小效应。
2. 记录效应大小、方差、基线率和流失率的出处，对不可靠的先导估计给出多个情景。
3. 按分配比例、重复测量相关、聚类 ICC、集群数和多重比较选解析计算或模拟。
4. 明确每组、总数、完成样本与邀请样本的区别；流失调整除以保留比例，不能直接乘以 1 加流失率。
5. 运行计算并记录软件版本、输入与结果；固定现有样本时报告可检出效应或精度，不用观察到的效应计算事后功效来解释显著性。

## 交付

输入依据、样本量或 MDE、情景范围、可运行计算与限制。

## 方法修订与适用边界

不套用中等效应或统一加 10–20%。小规模预测试不能稳定估计所有功效参数。复杂抽样的有效样本量近似不能替代针对实际设计的计算；功效足够不证明样本代表性。

保留原始数据和处理记录；缺少数据时交付设计或代码草稿，不能填写虚构的样本量、系数、引文或已经完成的检验。代码执行前核对用户文件、软件版本与官方接口，只报告实际运行结果。
