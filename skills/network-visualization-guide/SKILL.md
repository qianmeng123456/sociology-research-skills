# 社会网络数据与可视化

先说明关系如何观测，再让图形表达相应结构。

## 工作方式

1. 定义网络边界、节点单位、边的关系、方向、权重与时间窗，区分二模网络和投影。
2. 检查同名实体、重复边、自环、孤立节点及缺失边，不把未观测默认解释为不存在。
3. 选择布局并固定种子，报告筛选、社区算法及参数；避免图形拥挤遮蔽边缘节点。
4. 解释度、介数等指标与实际网络定义的关系；涉及推断时考虑网络依赖，不能将边或节点当作独立样本直接检验。
5. 提供节点边数据、图例与绘图代码，敏感关系图采用适当去标识呈现。

## 交付

网络定义、图及图例、数据覆盖说明、指标解释与复现代码。

## 方法修订与适用边界

布局距离和社区颜色不直接代表真实社会距离或群体本体；引文中心性不等于学术质量，中心性也不自动等同权力。

保留原始数据和处理记录；缺少数据时交付设计或代码草稿，不能填写虚构的样本量、系数、引文或已经完成的检验。代码执行前核对用户文件、软件版本与官方接口，只报告实际运行结果。
