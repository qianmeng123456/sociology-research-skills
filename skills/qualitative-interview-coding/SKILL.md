# 质性访谈与编码

确定任务阶段、研究问题、研究者立场、材料来源与所采用方法。只编码实际提供的材料；教学造例显著标为合成，不能伪装成访谈证据。

## 访谈设计

根据研究问题选择目的性、最大差异、案例对比或理论抽样并说明进入场域及关系限制。研究问题不直接等于问受访者的问题：从具体事件、过程、选择、关系和变化提问，再追问解释与反例。避免“是不是因为……”式理论灌输。

提纲包含开场与真实同意说明、经历时间线、核心主题、非诱导追问、反例和结束。录音与外部转录按用户和参与者授权范围处理；未获真实同意不能代填“已同意”。敏感材料采用稳定匿名 ID，保留原始材料于用户指定受控位置。

## 从材料到解释

1. 建立材料 ID 和行号/时间戳，核对机器转录的不确定词、说话人和上下文。不可将清理口语变成改写意思。
2. 初读形成个案摘要和反思记录。标记谁说、对谁说、何种情境与提问方式，避免只摘脱离语境的金句。
3. 按方法选择编码。反思性主题分析以研究者解释和反复发展主题为中心；代码本/框架分析可使用定义、纳入与排除条件；扎根理论的持续比较、理论抽样及编码方式依流派说明，不能仅做三级标签就自称扎根理论。
4. 建立 `材料位置 → 原文片段 → 描述/解释代码 → 分析备忘录 → 候选主题/机制`。反思性路径保留演变记录，不强制冻结代码本；代码本路径记录版本和歧义处理。
5. 比较个案与负例，保存矛盾和替代解释。主题是有组织意义的解释，不一定等于问题提纲的话题；提及次数不能直接等同社会重要性或总体比例。
6. 给结论限定资料范围。没有实际迭代与抽样证据时不称为“达到饱和”；合成、缺失或不可定位的引文不得用于实证论证。

## 交付

按阶段交付抽样与提纲、去标识转录、可定位编码记录、方法相符的备忘录/代码本、反例与主题论证。报告研究者位置、资料选择和解释决策。

编码一致性适用于某些代码本或内容分析设计，需要独立评价样本及与任务相符指标；不能把 κ 门槛当作反思性主题分析的通用标准。参考 [Braun 与 Clarke 方法说明](https://www.thematicanalysis.net/faqs/)。
