# 系统文献检索与综述

让检索与筛选可复查；先判断是否确实需要系统综述。

## 工作方式

1. 明确问题、人群、概念、情境及研究类型，制定纳入排除规则；社会问题不强套 PICO。
2. 记录数据库、完整检索式、字段、日期、语言与时间限制；有权限的中文数据库可与国际文献互补。
3. 保留稳定记录 ID 与 DOI，检查去重，再按标题摘要和全文筛选；注明单人或多人筛选方式。
4. 全文不可得标为待获取或无法评估，不能把摘要推测写成全文判断。提取设计、测量、样本、发现和局限并链接到来源位置。
5. 汇总筛选流转与理由；以当前适用的 PRISMA 等报告指引检查透明度，区分证据强弱与研究空白。

## 交付

检索日志、筛选记录、证据提取文件、流程计数及可核查综述。

## 方法修订与适用边界

普通网页搜索不能默认称为穷尽的系统检索。PRISMA 是报告规范，不是研究质量认证；不要声称不存在未实际检索的研究。

保留原始数据和处理记录；缺少数据时交付设计或代码草稿，不能填写虚构的样本量、系数、引文或已经完成的检验。代码执行前核对用户文件、软件版本与官方接口，只报告实际运行结果。
