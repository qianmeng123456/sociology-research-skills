# 统计假设检验

使检验服务于研究问题，区分描述、探索和预设确认性分析。

## 工作方式

1. 确定观测单位、独立或配对结构、结局尺度、零假设与估计目标。
2. 检查设计假设和异常值来源，选择 Welch、配对检验、合适的分类数据模型或非参数方法；不仅凭正态性检验的 p 值选方法。
3. 聚类、复杂抽样、重复测量按设计处理标准误；置换检验需说明可交换性。
4. 事先界定比较家族及控制 FWER 或 FDR 的方式，区分主要与探索性结局。
5. 报告效应量、置信区间、精确 p 值、分析样本及限制。等效性问题需定义等效界限并使用适用检验。

## 交付

检验选择理由、代码及实际结果、效应量和区间解释。

## 方法修订与适用边界

p 值不是零假设为真的概率；不显著不是相等，显著不是效应大或具有因果性。非参数检验也有设计和分布假设。

保留原始数据和处理记录；缺少数据时交付设计或代码草稿，不能填写虚构的样本量、系数、引文或已经完成的检验。代码执行前核对用户文件、软件版本与官方接口，只报告实际运行结果。
