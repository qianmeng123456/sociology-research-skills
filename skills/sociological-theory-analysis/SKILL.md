# 社会理论分析与研究问题

先区分文本解释、理论比较和经验转化。使用用户提供的版本与研究问题；未拿到原文只能给有标注的概述，不能假造页码或逐字引文。

1. 定位作者试图解决的具体问题、对话对象、历史语境与文本边界。思想家的不同阶段与文本不自动合成一个无矛盾体系。
2. 恢复核心概念及关系：定义、相邻概念、作用层次、适用条件和分析单位。区分作者自述、后人的解释及本次重构。
3. 按理论性质重建机制、意义关系或规范论证。不是所有解释都适合压成单向因果图；机制链应写清行动者、处境、资源、行动和聚合后果。
4. 比较理论时使用同一待解释问题，指出各自的解释范围、关键证据与相互不能互译的概念。不要只输出人物简介与优缺点列表。
5. 转为经验问题时，明确理论命题、范围条件、可观察含义、测量候选和竞争解释。提出能使主张受挫的证据，而非只寻找支持案例。
6. 假设写明变量方向、单位、时间、边界和机制，但区分解释性命题、因果假设与描述预期。若资料不支持识别，保留为待检验机制，不强行承诺因果效应。

交付按任务选择理论论证、概念关系图、理论—证据对应记录或研究问题候选。提出的贡献需说明相较哪组已核实文献改变了什么；未查全文的“研究空白”必须限定范围。

移交问卷时给构念定义、维度与代理局限；移交质性研究时给敏感化概念和竞争解释，不能把理论类别变成必须从访谈中找出的结论。
