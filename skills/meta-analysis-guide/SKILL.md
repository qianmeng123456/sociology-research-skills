# 元分析

先建立研究纳入依据和效应可比性，再汇总。

## 工作方式

1. 连接可追踪的检索、筛选与质量评价记录，确定目标效应、纳入范围和重复研究处理。
2. 提取效应定义、方向、标准误或可转换信息，保留页码和计算过程；不混合不兼容的调整后与未调整效应。
3. 处理同研究多结局、多时间或共享对照的依赖，选择适用的多层或稳健方法。
4. 依据研究异质性与目标选择模型，报告总体效应、区间、异质性及可适用的预测区间。
5. 评价偏倚和小样本效应，做影响与敏感性分析；预设调节分析与事后探索分开。

## 交付

提取数据、转换依据、分析脚本、合成结果及证据限制。

## 方法修订与适用边界

不以 I² 阈值机械选择固定/随机效应。小数量研究时漏斗图和 Egger 检验能力有限；显著合成效应不能消除原研究的偏倚或建立因果性。

保留原始数据和处理记录；缺少数据时交付设计或代码草稿，不能填写虚构的样本量、系数、引文或已经完成的检验。代码执行前核对用户文件、软件版本与官方接口，只报告实际运行结果。
