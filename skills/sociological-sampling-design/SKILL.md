# 社会调查抽样与总体推断

区分目标总体、抽样总体、框覆盖人群、受邀者和实际应答者。明确地域、时间、资格、观测单位与主要估计量。

1. 核对可用名单、地址、机构或平台招募渠道；评估漏盖、重复、联系质量和无法进入的人群。网络问卷可以来自概率抽样，也可以是自愿样本，不能仅按模式分类。
2. 概率设计写清阶段、分层、PSU、抽取与户/机构内选择规则、入样概率和替补政策。非概率设计写明便利、配额、滚雪球或平台自愿机制，并限定推广。
3. 先按主要估计的精度或功效规划完成样本；聚类设计考虑 ICC、集群大小差异和集群数，罕见群体需单独保证可分析数量。简单比例公式只适用于相应假设的近似计算。
4. 若用有限总体修正，注明无放回抽样及抽样比例等条件；按资格率、联系率、响应率或保留率的定义折算邀请数，避免重复调整同一损失。
5. 概率权重由入样概率出发，说明非应答调整、校准目标、修剪与偏差/方差取舍。保留权重版本，采用能处理分层/聚类/复制权重的方差估计。
6. 记录 dispositions 和响应率口径，联系当前 AAPOR 定义说明资格未知者处理。高响应率不自动无偏，低响应率也不直接量化偏倚。
7. 比较已知总体边际与应答者，讨论未观测选择、极端权重、覆盖以及选择模型的敏感性。

交付总体与抽样设计、样本规划输入/计算、招募路径、权重与方差处理说明、非应答记录计划及推广边界。

非概率样本不能只靠人数大或边际加权就获得设计型代表性；如报告模型型不确定区间，要交代选择模型等假设，不能冒称简单随机抽样误差。

方法入口：[AAPOR 调查实践](https://aapor.org/standards-and-ethics/best-practices/)。估计软件与标准定义在实际执行时核对。
